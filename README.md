# Pawnshop Marketplace (MVP)

Проект представляет собой платформу, которая связывает клиентов и ломбарды. Клиенты могут загружать товары для оценки, а ломбарды — оставлять свои предложения. Система уже работает на 75–80% и скоро будет расширена функцией чата.

---

## 📌 Основные возможности проекта

### 1. Регистрация и авторизация

* Регистрация клиентов (email / телефон)
* Регистрация ломбардов с указанием названия, контактов
* Возможность входа в систему для всех типов пользователей

### 2. Добавление товара клиентом

* Загрузка фото товара
* Указание названия, категории, состояния, описания
* Возможность указать примерную цену
* Указание города или района для локального поиска

### 3. Просмотр товаров для ломбардов

* Ломбарды видят товары, которые были выставлены клиентами
* Фильтрация по городу

### 4. Оставление предложений

* Ломбард может отправить своё предложение по цене
* Возможность указать срок действия предложения

### 5. Работа с предложениями клиента

* Клиент видит все полученные предложения от ломбардов
* Может выбрать лучшее
* Получает контакты ломбарда для дальнейшего взаимодействия

### 6. Уведомления

* Клиент получает уведомления о новых предложениях
* Пользователь получает все роды уведомлении(изменения цены продукта, продукт продан, ушел в архив и тд)
* Ломбарды — уведомления о новых лотах

### 7. Админ-панель (простая)

* Просмотр пользователей, лотов и предложений,аналитика
* ВОзможность быстро расчитать сумму займа и все проценты
* Возможность модерации контента

---

## 💡 Идея проекта

Проект создаёт простую и удобную площадку, где клиенты могут быстро получить оценку своих вещей от нескольких ломбардов одновременно. Вместо того чтобы обходить разные точки офлайн, пользователь загружает фото и описание, а ломбарды сами отправляют свои предложения. Это экономит время, делает рынок прозрачнее и помогает клиенту выбрать лучшее предложение.

## 🎯 Польза проекта

* Клиенты получают **минимальные хлопоты** и видят **реальные конкурентные предложения**.
* Ломбарды получают **поток горячих лидов**, которые уже заинтересованы в продаже.
* Платформа создаёт **справедливую систему цен**, убирая необходимость сравнивать вручную.
* Уведомления и будущий чат ускоряют процесс общения.

## 🚀 Текущее состояние проекта

* **Готово:** ~75–80%
* Основные функции реализованы: регистрация, добавление товаров, просмотр лотов, обмен предложениями
* В разработке: **чат между клиентом и ломбардом**
